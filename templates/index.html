Battery SoC Estimation with Dual UKF

This Battery Management System uses a Dual Unscented Kalman Filter (DualUKF) for real-time State of Charge estimation. The system simultaneously estimates battery states (SoC, RC voltage) and adapts parameters (capacity, resistance) using a dense neural network OCV model with MinMax scaling. Features include <1% typical error, temperature compensation, robust noise handling, and vectorized inference at 1 Hz update rate (configurable).

Algorithm

  • State Filter: Estimates SoC and U_d every timestep
  • Parameter Filter: Adapts Q_max and R_0 every 100 steps
  • OCV Model: Dense neural network with MinMax scaling
  • Battery Model: Equivalent circuit with RC pair
  • Tuning: Square-root formulation for numerical stability

Key Features

  • Real-time SoC estimation with <1% typical error
  • Adaptive capacity and resistance tracking
  • Temperature-compensated OCV lookup
  • Robust to measurement noise and model uncertainty
  • Vectorized observation for fast inference

Technical Specs

Model Architecture:

Dense NN

OCV prediction with SoC + Temperature inputs


Update Rate:

1 Hz

Default sampling period (configurable)

Filter Tuning

State Estimation:

  • Process Noise (State): 1e-6
  • Process Noise (Params): 1e-8, 1e-9
  • Measurement Noise: 1e-2

Constraints:

  • SoC: Clipped to [0, 1]
  • Capacity: Min 0.1 Ah
  • Resistance: Min 1e-4 Ω

Battery Model

  • Circuit: OCV + R0 + RC pair (R_D, C_D)
  • State: [SoC, U_d] - charge level and diffusion voltage
  • Parameters: [Q_max, R_0] - capacity and ohmic resistance
  • Coulomb Counting: SoC updated via current integration
  • RC Dynamics: Exponential decay with time constant R_D×C_D

Usage Guide

Step 1: Initialize filter with battery parameters (capacity, initial SoC, R0, sampling period)

Step 2: Stream V, I, T measurements from BMS at each timestep

Step 3: View real-time SoC estimates and trend on the chart

Tip: Use scroll wheel or pinch gesture to zoom on the chart for detailed inspection
