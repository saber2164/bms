Algorithm

  • State Filter: Estimates SoC and diffusion voltage
  • Parameter Filter: Adapts capacity and resistance
  • OCV Model: Linear approximation (3.0V-4.2V)
  • Square-root formulation for stability

Battery Model

  • Equivalent circuit: OCV + R0 + RC pair
  • State vector: [SoC, U_d]
  • Parameter vector: [Q_max, R_0]
  • Coulomb counting with current integration

Filter Parameters

  • Process Noise (State): 1e-6
  • Process Noise (Params): 1e-8, 1e-9
  • Measurement Noise: 1e-2
  • SoC constrained to [0, 1]

Usage

  • Initialize filter with battery parameters
  • Input voltage, current, temperature
  • Click Estimate to run UKF step
  • Scroll/pinch to zoom the chart
